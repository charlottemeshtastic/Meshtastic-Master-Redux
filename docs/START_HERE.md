# Start here

[Back to the index](../README.md) · [Troubleshooting](TROUBLESHOOTING.md) · [Deployment planning](DEPLOYMENT.md)

Follow this path for your first pair of radios. The linked official documentation is the authority for your device and firmware version.

| Step | What to do | Reference |
| --- | --- | --- |
| 1. Identify your device | Confirm the exact board, supported firmware and radio band before choosing accessories. | [Supported hardware](https://meshtastic.org/docs/hardware/) |
| 2. Prepare the connection | Attach the appropriate antenna and use a USB data cable when flashing over USB. | [Getting started](https://meshtastic.org/docs/getting-started/) |
| 3. Flash the correct firmware | Follow the instructions for your board family. Keep a private backup of an existing configuration before erasing it. | [Flashing firmware](https://meshtastic.org/docs/getting-started/flashing-firmware/) |
| 4. Connect an app | Choose the official Android, Apple, web or Python client and a connection method your board supports. | [Software](https://meshtastic.org/docs/software/) |
| 5. Configure both radios | Set the appropriate region, then compare modem preset, frequency slot and messaging channel settings. | [Initial configuration](https://meshtastic.org/docs/getting-started/initial-config/) |
| 6. Send a first message | Start with two nearby radios using matching settings. Confirm receipt on the second device before testing longer distances. | [Channel configuration](https://meshtastic.org/docs/configuration/radio/channels/) |
| 7. Join your local mesh | Ask a local group about its settings and test your node before permanent placement. | [Community directory](../COMMUNITIES.md) |

## Choose your next path

- A phone-connected handheld: use the official apps under [official resources](../README.md#official-resources).
- A Linux computer or Raspberry Pi node: read [Linux and Raspberry Pi](LINUX.md).
- A fixed or solar node: use [deployment planning](DEPLOYMENT.md).
- A connection or delivery problem: use [troubleshooting](TROUBLESHOOTING.md).

These steps are a navigation aid. Menus and supported features change; check the documentation that matches your firmware rather than copying another mesh's settings.
